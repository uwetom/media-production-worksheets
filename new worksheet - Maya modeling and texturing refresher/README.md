# Maya Refresher

You may be a little rusty with Maya, this worksheet will remind you of the basic of modeling and common shortcuts.

## Navigation

To move around your viewport:

- **Orbit** - Alt + left mouse button
- **Pan** - Alt + middle mouse button
- **zoom** - scroll mouse wheel

Tap the space bar to move between scenes.

## Modelling

### Primitives and Manipulation

You can create primitive shapes from the top menu, double click to open the options.

Manipulate objects and components

- **Move** - w
- **Rotate** - e
- **Scale** - r

![primitive shapes in Maya](images/primitives.jpg)

[<img alt="video showing how to create and manipulate primitives in maya" src="images/video-2-manipulation.jpg">](https://uwe.cloud.panopto.eu/Panopto/Pages/Viewer.aspx?id=9cac5e48-d98e-4bc5-a441-b49f009b2461)

### Tools

To change between object, vertex, edge and face mode, you can use the toolkit

![toolkit in maya](images/toolkit.jpg)

The toolkit also contains some useful ways to manipulate and add more detail to your object

- Extrude
- Multi-cut
- Bevel

[<img alt="video showing how to use tools in Maya" src="images/video-3-tools.jpg">](https://uwe.cloud.panopto.eu/Panopto/Pages/Viewer.aspx?id=b3081523-e90c-483a-95f2-b49f009c2aa9)

## Texturing

We can apply colours and PBR materials to our objects.

I recomend the standard surface material for rendering as it will give the most realistic renders.

[<img alt="video showing how to texture objects in Maya" src="images/video-4-materials.jpg">](https://uwe.cloud.panopto.eu/Panopto/Pages/Viewer.aspx?id=55a852e2-5485-4805-ab5b-b49f009e26a8)
